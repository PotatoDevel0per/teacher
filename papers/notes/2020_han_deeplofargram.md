## 한 문장 요약 (arXiv v1 기준)

LOFARgram 이미지를 AlexNet/VGG 분류기에 넣어 "선 있음/없음"(H1/H0)을 판정하고, H1 점수를 입력 이미지로 미분한 saliency map(guided backprop)을 "선 위치 지도"로 쓴다. 두 출력을 함께 학습하는 multi-task loss를 둔다. 출력은 **픽셀 단위 확률 지도**이고, 주파수 궤적 f(t)를 숫자로 뽑는 단계는 없다.

## 처음 나오는 개념 (짧은 정의)

- **LOFARgram**: 신호를 긴 window로 잘라 FFT한 크기 스펙트럼을 시간 순서로 쌓은 이미지(가로 주파수, 세로 시간). tonal은 세로선으로 보인다.
- **dim / fluctuating line**: dim = SNR이 낮아 눈에 안 보이는 선. fluctuating = 주파수가 시간에 따라 불규칙하게 흔들리는 선. 흔들리면 같은 bin에 에너지가 쌓이지 않으므로 "오래 평균하면 보인다"가 통하지 않는다(원문 서론의 핵심 동기).
- **Random walk 주파수 모델**: f_t = f_{t−1} + (작은 무작위 변화). 다음 순간 주파수를 예측할 수 없는 흔들림의 가장 단순한 모델이다.
- **Saliency map (Simonyan 2014)**: 분류 점수 s1을 입력 픽셀로 미분한 값. "어느 픽셀을 바꾸면 '선 있음' 점수가 가장 많이 변하는가"를 보여 준다.
- **Guided backpropagation (Springenberg 2015)**: saliency를 계산할 때 ReLU에서 순방향 입력이 양수이고 역방향 기울기도 양수인 경로만 통과시킨다. 결과가 덜 지저분하다.
- **ROC / PD / FAR**: 문턱을 바꾸며 그린 (오경보율, 검출률) 곡선. 여기서는 **LOFARgram 1장 단위**의 판정이다(픽셀·프레임 단위가 아님).
- **LLA (line location accuracy, Lampert & O'Keefe 2013)**: 예측한 선 픽셀마다 가장 가까운 정답 선 픽셀까지 거리 d를 재고 1/(1+λd)를 더한 뒤 max(|P|,|F|)로 나눈다. 완전히 맞으면 1, 멀수록 0에 가깝다. 선을 과하게 칠하면 분모가 커져 깎인다.

## 확인한 내용 (`confirmed`, arXiv v1 기준)

### 1. 입력과 출력 (handoff 확인 항목 1, 2)
- 입력: LOFARgram I ∈ [0,255]^{T×K}. 원본 크기 **500 × 256**(시간 500 × 주파수 256으로 보임, 축 대응은 명시 안 됨). 학습 시 224 × 224 patch를 잘라 씀(§III.C.1).
- **LOFARgram 생성 파라미터(표본화 주파수, window 길이·종류, overlap, Δf, 주파수 범위, 정규화 방법, [0,255] 양자화 방법)는 하나도 없다.** TeX 주석에도 없다.
- 출력 ①: H0/H1 softmax 확률 (LOFARgram 1장당 1개)
- 출력 ②: 선 확률 지도 P = sigmoid(S), S = ∂s1/∂I (guided backprop). 픽셀 단위.
- 주파수 궤적 추출, 다중 선 처리, 선 개수 추정은 **없다**. 한 장에 선은 최대 1개다.

### 2. 학습 데이터 (항목 3)
- 신호 모델 (식 4, Paris & Jauffret 2003 [11]을 따름): s_t = a_t sin(2π f_t t + φ_t) + ε_t, ε_t ~ N(0, σ_t²). f_t는 random walk.
- **random walk 파라미터(걸음 크기 분포, 중심 주파수, 경계 처리), 진폭 a_t 변화, 위상 φ_t, 표본화 주파수는 원문에 없다.** "[11]과 같은 설정"이라고만 쓴다. [11]은 IEEE TAES 39(2):439–449 (유료, 미확보).
- SNR 정의: 시간 영역 SNR = 10 log10(a²/(2σ²)). 실험 SNR: −20, −22, −23, −24, −25, −26 dB.
- 데이터 규모: SNR마다 H0 1000장 + H1 1000장. 90% 학습 / 10% 시험 (시험 200장).
- 라벨: h ∈ {0,1}, 선 지도 F ∈ {0,1}^{T×K}. F를 만드는 방법(선 폭 몇 bin인지, f_t를 bin에 어떻게 반올림하는지)은 **없다**. "정답 픽셀의 90%가 비-선"이라는 서술만 있다.
- 실데이터: **사용하지 않음.** 합성 데이터만. TeX 주석에 Lampert 데이터셋(4142장) 비교 계획이 있었으나 본문에서 빠짐.
- 증강: 상하·좌우 반전(×8이라고 씀) + 224×224 무작위 patch 4개 → 원본 대비 ×32.

### 3. 네트워크와 학습 설정 (항목 4)
- 검출망: ImageNet용 AlexNet 또는 VGG8/11/16/19, 마지막 층을 2-way로 바꿈. ImageNet 사전학습 가중치 사용 여부는 **명시 안 됨**.
- 복원망: 검출망의 "거울" = 같은 가중치로 guided backprop. 별도 파라미터 없음.
- Loss (식 2–3): L = −log p_h + 1(h=1) · L_rec. L_rec = class-balanced BCE (β = |F−|/|F|, HED 방식; 원문은 인용이 빈 칸 "[]").
  - L_rec가 입력 기울기의 함수이므로 학습에 **2차 미분(double backprop)** 이 필요하다(`inferred`, 원문은 언급 안 함).
- 최적화: Adam, batch 128, weight decay 10⁻³, 첫 두 FC dropout 0.5.
- 커리큘럼: (1) −20, −23 dB로 lr 10⁻³ 사전학습 → (2) lr 10⁻⁴로 −24, −25, −26 dB 학습. 각 100K iteration ("55 epochs"라고 병기).
- 계산 자원·학습 시간: **언급 없음.**

### 4. 평가 (항목 5)
- 지표: ROC(PD vs FAR, 장 단위 검출), LLA(λ = 1, 픽셀 위치 정확도).
- 비교 대상: CEM(contour energy minimisation, Lampert 2013), HMM 추적(Paris & Jauffret 2003). **두 방법은 LLA만 비교.** TPSW + 임계 같은 단순 기준은 **없다**.
- 결과 (그림에서만, 수치 표 없음):
  - 증강: 반전+이동 > 반전 > 없음, 모든 SNR (Fig. 2)
  - 깊이: AlexNet, VGG8–19 성능 비슷 (Fig. 3)
  - guided BP가 BP보다 LLA 조금 높음, 높은 SNR에서 차이가 큼 (Fig. 4a–e)
  - SOTA 비교 (Fig. 4f, 본문 수치): DeepLofargram LLA 0.28–0.45, CEM ≈ 0.14 일정, HMM ≤ 0.1
  - 초록: "performance boundary −24 dB 평균, 일부 −26 dB". 이 "경계"의 정의(PD 몇 %에서인지)는 **없다**.
- 반복 실행: **없음.** 시험 200장, 실현 1회, 분산·신뢰구간 없음.

## 비판적 검토 (`inferred`)

1. **SNR 숫자를 그대로 비교할 수 없다.** −24 dB는 시간 영역 SNR이다. LOFARgram 한 칸의 SNR은 FFT 길이와 window에 따라 수십 dB 달라진다. 원문은 N을 밝히지 않았으므로 "−24 dB까지 된다"를 다른 조건(특히 사용자의 5 s 클립)으로 옮길 수 없다.
2. **검출은 장 단위다.** PD/FAR은 "이 LOFARgram 전체에 선이 있나"다. 사용자에게 필요한 "어느 주파수에 tonal이 있나"(bin 단위 검출률·오경보율)와 다르다. 단계 2에서는 bin·프레임 단위 지표를 따로 정의해야 한다.
3. **복원 결과는 확률 지도다.** 주파수 RMSE를 내려면 프레임마다 argmax 등으로 궤적을 뽑는 후처리를 직접 정해야 한다(원문에 없음 → 재현 시 변형).
4. **비교 대상이 약하다.** 단순 기준(TPSW + 임계, 시간 적분)이 없다. CEM은 "기저 주파수 사전정보만 복원"(원문 서술)했다고 하고, HMM은 "완전히 실패"했다. 두 방법을 어떤 파라미터로 돌렸는지 없다. 기준선이 제대로 조정됐는지 확인할 수 없다.
5. **통계적 근거가 약하다.** 시험 200장, 1회 실행, 분산 없음, 수치 표 없음(그림만).
6. **saliency를 위치 지도로 쓰는 것의 한계.** 기울기 지도는 "점수에 영향을 주는 픽셀"이지 "선이 있는 픽셀"과 같지 않다. 그래서 loss로 기울기 자체를 정답 지도에 맞추도록 강제한다(2차 미분). 이 설계가 U-Net 같은 직접 분할보다 나은지 원문은 비교하지 않았다. 게재판이 U-Net을 인용한 것은 이 점을 보완했을 가능성.
7. **도메인 차이.** 단일 선 + 백색 Gaussian 잡음. 실제 선박 소음은 다중 하모닉, 유색(colored) 광대역 배경, 다른 선박 tonal이 섞인다. 저자도 한계로 인정.

## 사용자 연구와의 관계 (`inferred`)

- 장점: 단일 채널 LOFARgram 입력, 약한·흔들리는 tonal에 초점 → OP6(tonal 보존 평가)의 "tonal 위치 추출기" 후보.
- 단점: 출력이 궤적 숫자가 아니라 확률 지도. 단일 선만. 사용자의 5 s 클립(Δf ≥ 0.2 Hz, 프레임 수 적음)에서 500 프레임 LOFARgram을 만들 수 없음 → 입력 크기부터 달라짐.
- 학습 기반이라 합성 데이터 설정이 곧 성능 범위를 정한다. 합성 설정이 원문에 없으면 "재현"이 아니라 "아이디어 기반 변형"이 된다.

## 계산량 추정 (`inferred`)

- 원문 규모: AlexNet/VGG, 224×224, batch 128, 100K iter × 2 단계 × (SNR별?) + 2차 미분. GPU 1장 기준 AlexNet은 단계당 수 시간, VGG16/19는 수십 시간 수준으로 추정. **CPU로 원문 규모는 비현실적.**
- CPU 소규모안: 작은 CNN(수십만 파라미터) + 128×128 이하 입력 + 수천 iteration → 조건당 수십 분 이내로 추정. 이 경우 표현은 "아이디어 기반 변형"이다.

- 단계 2는 판정 확정 전에는 시작하지 않는다. 이유: 게재판의 방법(복원망 구조)과 합성 설정이 arXiv와 다르면, arXiv 기준으로 만든 재현이 무효가 된다.

## 왜 이 단계가 필요했나 (사용자 설명용)

- 초록만 보면 "−24 dB까지 검출"이 강한 결과로 보인다. 원문을 읽으면 이 숫자가 (1) 시간 영역 SNR이고, (2) FFT 길이를 모르면 해석할 수 없고, (3) 장 단위 판정이라는 것이 드러난다. 이런 조건을 모르고 사용자 데이터(5 s 클립)에 기대 성능을 옮기면 틀린 결론을 낸다.
- 재현 전에 "빠진 파라미터 목록"을 만드는 이유: 빠진 값을 내가 채우면 그만큼 논문 방법이 아니라 내 변형이 된다. 그 비율이 크면 재현 결과로 논문을 평가할 수 없다.
