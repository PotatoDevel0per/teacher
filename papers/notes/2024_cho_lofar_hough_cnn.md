## 확인한 내용 (`confirmed`, 원문)

### 데이터
- DeepShip 4클래스 일부 + ShipsEar Passenger ship (§3.1)
  - Table 1: Cargo 59 / Tanker 64 / Passenger 70 / Tug 32개 파일
- 1분 segment로 자른다. LOFARgram 928장(256×256)을 만든다.
- 분할: "생성한 이미지는 7:3 비율로 훈련/테스트 분할"(§3.1). 녹음 단위 분리에 대한 언급이 없다. val set도 언급이 없다.

### LOFAR 생성
- fs 32 kHz, overlap 50%, "윈도우 크기 100", 대역 2–400 Hz
- "정규화 과정을 통해 소음을 제거한다"는 서술만 있다. 정규화 방법(TPSW 등)은 적혀 있지 않다.

### Hough 변환
- 순서: 외곽선 추출 → (θ, ρ) 누적 → 임계 이상 점을 직선으로 인식
- 임계값은 "시각적 판단"으로 정했다. 비교한 값은 50 / 130 / 200이고, 최적값은 130이다(Fig. 6).
- 기울기 0인 직선만 남기고 빨간 선으로 덧그린다.

### 결과 (Table 6, 1회 실행)
- 정확도 향상: +3.56(ResNet18) ~ +5.70(3-layer CNN) pp
- 본문의 F1 향상 폭(0.0431–0.059)이 Table 6(0.0380–0.0583)과 맞지 않는다.

### 수작업 해석 (Fig. 8)
- Tug(NORTH ARM): 기본 주파수 15.2 Hz 계열(22번째 하모닉까지)과 91.5 Hz 계열
- 저자는 이 두 계열을 CSR/CFR과 EFR로 해석해 "약 900 r/min, 6기통 엔진"으로 추정했다.
- 정답(실제 엔진 사양)으로 확인한 것은 아니다.

## 해석 (`inferred`)

- **특징 추출 성능은 평가하지 않았다.** tonal 검출률이나 오경보율 같은 지표가 없고, 분류 정확도만 있다. 그래서 LOFAR 세션의 확정 기준 (b)를 충족하지 못한다.
- **분할 누수 가능성이 높다.** 같은 녹음에서 나온 1분 segment가 train과 test에 함께 들어갔을 가능성이 높다. 정확도와 향상 폭이 모두 부풀려졌을 수 있다(UniqueShip 논문의 논지와 같은 사례).
- **데이터셋 지름길 가능성이 있다.** Passenger만 ShipsEar가 섞여 있다면, 분류기가 선종 대신 녹음 장비나 해역을 구분할 수 있다.
- **"윈도우 크기 100"은 단위가 맞지 않는다.** 100 샘플(32 kHz)이면 Δf가 320 Hz라서 15.2 Hz 하모닉 분석과 모순된다. 100이 다른 단위(예: 초)일 가능성이 있지만 확인할 수 없다.
- **쓸 수 있는 부분**
  - Hough 수평선 검출은 비학습 tonal 검출 기준선으로 쓸 수 있다. CPU로 돌릴 수 있고 설명하기 쉽다.
  - Fig. 8의 하모닉 계열 → 엔진 rpm·기통 수 해석은 LOFAR에서 얻을 수 있는 물리 정보의 예다. 사용자가 개념을 익히는 데 쓸 수 있다.

- Fig. 8의 "30번째 Cargo(SEASPAN SWIFT)"와 "20번째 Tug(NORTH ARM)"는 DeepShip 녹음 ID와 정확히 맞는다. 즉 원문은 DeepShip 녹음 ID 체계를 썼다.
  - Cargo/20171120-30 = SEASPAN SWIFT (324 s)
  - Tug/20171122a-20 = NORTH ARM (718 s)
- Table 1의 이미지 수는 "파일별 1분 비중첩 분할 + 나머지 버림"과 맞는다.
- Table 2는 클래스별로 floor(0.7 × n)을 train으로 둔 층화 분할과 정확히 같다(186/124/152/185).
- ShipsEar Passengers 녹음은 30개다. 따라서 원문 Passenger 70개 = ShipsEar 30 + DeepShip 40으로 추정한다(`inferred`, 원문은 비율을 적지 않음).

### 왜 이 단계가 필요한가 (사용자 설명용)
- **R1(원문 분할 그대로)**: 같은 조건에서 원문 숫자가 다시 나오는지 확인한다. 나오지 않으면 R2에서 성능이 떨어져도 그것이 "누수가 사라져서"인지 "구현이 달라서"인지 구분할 수 없다.
- **R2a(녹음 단위)**: 같은 녹음의 연속 1분 조각은 배경 잡음과 선박 상태가 거의 같다. train과 test에 같이 들어가면 모델이 선종이 아니라 "이 녹음"을 외워도 맞힌다. 녹음을 한쪽에만 두면 이 지름길이 사라진다.
- **R2b(선박 단위)**: 같은 선박의 다른 녹음도 tonal 구성(엔진·기어)이 같다. 선박을 한쪽에만 두어야 "처음 보는 선박의 선종을 맞히는가"를 잴 수 있다. 사용자의 1순위 목표(MMSI 단위 분리)와 같은 조건이다.
- **HT 이득을 짝지어 비교하는 이유**: seed가 바뀌면 분할이 바뀌어 정확도가 몇 pp씩 흔들린다. 같은 seed·분할에서 원본과 +HT의 차이를 보면 분할 운에 따른 흔들림이 상쇄된다.

### 채운 값 (원문 미기재, `inferred`/구현 휴리스틱)

| 항목 | 채운 값 | 근거 |
|---|---|---|
| 파일 선택 | Fig. 8의 두 녹음 포함 + ShipsEar passengers 30 전부 + 나머지는 seed 0 무작위 시작 후 1개씩 교체해 Table 1의 길이·이미지 수에 맞춤 | 결과: 파일 수와 이미지 수 4클래스 모두 일치, 길이 오차 ≤ 0.15% |
| window | Hann, 14,940 샘플(0.467 s), hop 7,470 | "100"은 단위 모순. 50% overlap + 1분 = 256 프레임을 만족. Δf ≈ 2.14 Hz, Hann 분해능 ≈ 4 Hz → 15.2 Hz 간격 하모닉 분리. "100 ms"(Δf 10 Hz)는 13 Hz 하모닉 판독(Fig. 8a)과 맞지 않아 버림 |
| 주파수 축 | 2–400 Hz 선형 256점에서 DFT 직접 계산 | 256 × 256을 재샘플 없이 만듦 |
| ShipsEar 표본화 | 52,734 → 32,000 Hz (resample_poly) | 원문 fs 32 kHz. 원본 위치: `/jhlee/Underwater_Acoustic/LIG_Diffusion/Datasets/ShipSEAR/AUDIOS` |
| 정규화 | TPSW (반폭 16 bin ≈ ±25 Hz, gap 2 bin, α = 2.0), 10log10(P/bg)를 [0, 10] dB로 잘라 0–255 | 원문 미기재. handoff 지시대로 TPSW |
| 색 | green 채널만 사용 (Fig. 7의 검정–초록) | 그림 모양 |
| 시간 축 | 위쪽이 최근 (Fig. 8 축 방향) | 그림 |
| 외곽선 | Canny, high = Otsu 임계, low = 0.5 × high | 원문 미기재 |
| Hough | cv2.HoughLines, ρ = 1 px, θ = 1°, 누적 임계 130, θ = 0만 유지 | 130은 원문. 해상도는 채움 |
| 선 그리기 | 해당 열의 R = 255 (G는 유지 → 강한 선은 노랗게 보임, Fig. 8과 같은 모양) | 그림 |

| 증강 | 없음 | 원문에 언급 없음 |
| 분할 | 클래스별 floor(0.7 × 그룹 수)를 train으로, seed마다 새로 뽑음 | Table 2와 일치 |

### 원문과 다른 점 (편차)

- Hough 선이 굵은 tonal 하나의 양쪽 외곽선에서 2개씩 나올 때가 있다(원문 Fig. 8은 tonal당 1개로 보임).

  - ShipsEar 'arroios_sale_2entran'은 arroios로 합쳤다.
- R2a 키에 클래스를 넣었다. DeepShip 녹음 폴더명이 클래스 사이에 겹치기 때문이다(예: 20171106-4가 Cargo와 Tug에 모두 있음).

### 사전 등록 판정 기준 (teacher handoff 그대로)
- (i) ResNet18 원본 입력의 정확도 평균이 81.85 ± 5 pp 안

- 예시 그림 관찰 (`figs/class_examples_orig_vs_ht.png`, R1 결과 보기 전)
  - DeepShip 이미지 상당수에 기울어진 간섭 줄무늬가 있다(거리 변화에 따른 무늬로 추정, `inferred`). θ = 0만 남기는 Hough는 이 무늬를 잡지 않는다. 원문이 한계 둘째로 밝힌 것과 같다.
  - 2–8 Hz 가장자리 띠(TPSW 경계 효과)가 Hough 선으로 잡히기도 한다. 원문 Fig. 8에도 같은 띠가 보이므로 그대로 둔다.

- Hough 선 통계 기준선(로지스틱 회귀)과 CNN3 +Hough 비교:

  | 분할 | 선 개수 | 선 주파수 히스토그램 16칸 | CNN3 +Hough |
  |---|---|---|---|
  | 녹음 단위 | 39.8 | 35.2 | 53.1 |
  | 선박 단위 | 35.0 | 36.5 | 49.5 |

  - 선 통계만으로는 CNN3 +Hough에 13–18 pp 못 미칩니다.
  - 따라서 "Hough 이득 전체가 선 개수 단서에서 온다"는 가설은 지지되지 않습니다. 다만 단서를 일부 쓰고 있을 가능성은 배제하지 않습니다.
- 선박 단위 분할에서 Passenger recall은 출처에 따라 크게 다릅니다.
  - ShipsEar: 0.67–1.0
  - DeepShip: ResNet18 0.0–0.2, CNN3 0.33–0.48
  - 추론: 데이터셋 출처라는 지름길이 남아 있습니다. Passenger의 ShipsEar 30개 녹음은 4,278 s로 짧아서 이미지 수가 적습니다.
- CNN3의 Hough 이득이 나타나는 클래스(선박 단위 분할, 클래스별 F1):
  - Tug 0.369→0.491
  - Tanker 0.534→0.604
  - Cargo는 변화가 없습니다.
- 계산 시간: R2 전체(36 run, 3개 병렬 × 16 스레드)에 약 4.5 h가 걸렸습니다.

### 왜 필요한가
- 이미지 단위 분할에서는 같은 녹음에서 나온 1분 조각들이 학습셋과 테스트셋에 나뉘어 들어갑니다. 그래서 모델이 선박 자체의 소리를 외워도 점수가 나옵니다.
- 녹음 단위 분할과 선박 단위 분할은 이 경로를 차례로 막습니다. 이렇게 해야 처음 보는 선박에 대해 실제로 일반화하는지 볼 수 있습니다.

## [보조, 사후] 결합 분류기 (2026-10-13, C안: R2b 선박 분할, seed 0–2)

설계
- 입력: CNN3 원본 softmax의 로그값과 Hough 선 특징(선 수 + 16 bin 히스토그램)
- 분류기: 로지스틱 회귀(표준화 후)를 train 분할에서만 학습
- train 이미지의 CNN 확률은 선박 그룹 3-fold out-of-fold로 만들었습니다.
- test 이미지의 확률은 train 전체로 재학습한 CNN3 원본에서 얻었습니다.

결과

| 행 | 정확도 (%) | macro-F1 | balanced accuracy (%) | CNN3 +HT와의 정확도 차이 (seed 짝지음, pp) |
|---|---|---|---|---|
| CNN3 원본 (재학습) | 44.31±0.78 | 0.45 | 47.91 | −5.18 |
| LR(OOF 확률만) | 40.21±0.95 | 0.39 | 42.40 | −9.28 |
| LR(선 특징만) | 36.50±8.19 | 0.35 | 38.16 | −12.99 |
| LR(OOF 확률 + 선 특징) | 41.83±7.34 | 0.42 | 45.72 | −7.65 |
| CNN3 +HT | 49.49±1.86 | 0.50 | 52.52 | 0 |

확인됨
- 재학습한 CNN3 원본의 test 예측은 기존 run과 seed 3개 모두 완전히 같습니다. CPU에서 학습이 결정적으로 재현됐습니다.
- 확률만 쓰는 모델에 선 특징을 더하면 정확도가 seed별로 +9.6, −4.7, 0.0 pp 바뀝니다. 평균 +1.6±7.3 pp로 방향이 일정하지 않습니다.
- 결합 분류기는 CNN3 +HT보다 7.7 pp 낮습니다.
- 확률만 쓰는 로지스틱 회귀는 CNN3의 argmax보다 4 pp 낮습니다. 따라서 이 결합 방식 자체가 손실을 냅니다.
- OOF train 정확도는 40–46%로 test 정확도와 비슷합니다.

판정: 결론 보류 (inconclusive, Teacher 2026-10-13)
- "선 요약 정보로는 HT 이득이 설명되지 않는다"고 단정하지 않습니다.
- 확률만 쓴 로지스틱 회귀가 이미 CNN3 argmax보다 4.1 pp 낮습니다. 결합 방식 자체가 정보를 잃고 있어서, 이 검정으로는 선 특징의 효과를 가려낼 힘이 부족합니다.
- 결과의 방향은 선 통계 기준선 결과와 같습니다.
- 공간적 주의 가설(빨간 열 주변 tonal을 CNN이 쓰게 됨)은 기록만 하고 승인되지 않았습니다. 검증한다면 후보는 "선 열을 무작위 위치에 그린 대조 이미지"입니다.

미확인
- 다른 결합 방식(예: 선 특징을 CNN의 중간 층에 넣는 방식)은 시험하지 않았습니다.
