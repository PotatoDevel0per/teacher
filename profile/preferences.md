# Preferences

## 용어 표기 규칙 (2026-10-06 사용자 요청)

같은 개념을 여러 이름으로 부르지 않는다. 아래 표기로 통일한다.

| 개념 | 쓸 표기 | 쓰지 않을 표기 |
|---|---|---|
| 저주파 협대역 선 성분 | **tonal** | 선, 토널, 톤, 선 성분, 협대역 선 |
| STFT/FFT 분석 구간 | **window** | 창, 창 길이 → window length |
| 협대역 | **narrow** (예: narrow band) | 협대역 |
| 광대역 | **broad** (예: broadband) | 광대역 |

- 기존 문서를 수정할 때도 이 표기로 바꾼다.
