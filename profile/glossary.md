# Glossary

| 용어 | 정의 | 비고 |
|---|---|---|
| tonal | 저주파의 narrow 주파수 성분. 회전 기계, 날개 통과 등에서 생긴다 | 표기 규칙: `profile/preferences.md` |
| window | STFT/FFT를 계산하는 시간 구간과 그 가중 함수. window length N이 주파수 분해능 Δf = fs/N을 정한다 | |
| narrow / broad | 주파수 폭이 좁은 / 넓은 성분 | |
| DEMON | broadband 잡음 포락선의 스펙트럼. 축 회전수와 날개 수를 반영한다 | `research/concepts/stft_lofar_demon.md` |
| LOFAR | 긴 window와 배경 정규화로 저주파 tonal을 보는 스펙트로그램 | 같은 노트 |
