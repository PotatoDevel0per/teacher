# Research Goals

## 지도교수가 준 원래 연구 방향

- 수중 음향 표적 선박 소음 **생성 모델** (사용자 발언, 2026-10-06)
- 아래 1차 목표는 이 방향의 **선행 단계**로 계획됐다. 지도교수 승인 여부는 미확인이다.

## 갱신 (2026-10-19, D-2026-10-19-01)

- 학위논문. 지도교수 1순위는 생성 모델(사용자 확인).
- **주 방법: 증강용 생성 모델.** 목표는 선박 분리 분할에서도 일반화되는 클래스 변별 특징을 가진 샘플이다. WAV 복원은 나중이다.
- 판정 기준은 아래 1차 목표의 것(누수 없는 UATR 일반화)을 그대로 쓴다. 비생성 물리 증강은 비교 기준으로 남긴다.
- 자원: A5000 2장.

## 1차 목표 (2026-10-06 사용자 결정, D-2026-10-06-02; 주 방법은 D-2026-10-19-01로 대체)

**물리 기반 데이터 증강으로 UATR의 누출 없는(unseen-vessel) 일반화를 개선한다.**

- 주 벤치마크: UniqueShip 5 Class - Balanced. 공식 MMSI 분리 5 fold, baseline Swin Mel 0.665 ± 0.012
- 보조: DeepShip 선박 분리. sd가 커서 보조 지표로만 쓴다.
- "물리 기반 증강"의 정의는 미정이다. 후보: 레벨·거리(전파손실), 배경 잡음 SNR, 도플러·축 회전수 변화, 생성 모델 기반 증강

## 후순위

- WAV 복원 및 생성 파이프라인(LDM 먼저, LFM 나중). 음향학적 타당성 평가(OP11)
- 수중음향 도메인 특화 임베더와 생성 평가
