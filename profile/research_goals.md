## 1차 목표 (2026-10-06 사용자 결정, D-2026-10-06-02)

**물리 기반 데이터 증강으로 UATR의 누출 없는(unseen-vessel) 일반화를 개선한다.**

- 주 벤치마크: UniqueShip 5 Class - Balanced. 공식 MMSI 분리 5 fold, baseline Swin Mel 0.665 ± 0.012
- 보조: DeepShip 선박 분리. sd가 커서 보조 지표로만 쓴다.
- "물리 기반 증강"의 정의는 미정이다. 후보: 레벨·거리(전파손실), 배경 잡음 SNR, 도플러·축 회전수 변화, 생성 모델 기반 증강

## 후순위
