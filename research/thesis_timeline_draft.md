## 결정점과 대체 경로

- **DP1 (약 11/22) G1이 2회 실패:** LDM·LFM을 보류한다(D-2026-10-06-01). 논문은 "비생성 물리 증강 + tonal·DEMON 평가 방법 + 생성 latent 병목의 음성 결과"로 바꾼다. 일정은 약 8주 단축된다.
- **DP2 (약 1/17) 제어 실패:** H-LDM-3(보조 손실) 또는 H-LDM-4(guidance)를 하나만 시도한다(+2–3주). 그래도 실패하면 A-ldm-real(실제 조건 생성)까지만 판정하고 조건 조작은 한계로 기술한다.
- **마감이 더 이르면 줄일 순서:**
  1. DeepShip 재확인
  2. 분류기 3종 확인 → 1종
  3. c_DEMON 조건 → c_LOFAR만
  4. ablation 축소
  - 단계 5의 A0 / A-gen / A-phys / A-ldm 비교는 줄이지 않는다. 논문의 주장 자체이기 때문이다.

## 일정 위험

- **지도교수 방향 미승인:** D-2026-10-06-02(1차 목표 변경)는 승인되지 않았다. 0–1주에 확인하지 않으면 전체 일정이 바뀔 수 있다. 가장 큰 위험이다.
- **A-phys(D4) 미설계:** 이것이 없으면 "조건부 LDM이 비용을 정당화한다"(D-2026-10-13-02 조건 2)를 판정할 수 없다. 후보: 수중 채널(전달손실·다중경로) 합성곱, 속도 변화에 따른 tonal 이동, 실측 배경잡음 혼합. 모두 `hypothesis`이고 문헌을 확인해야 한다.
- **GPU 시간:** 단계 5의 run 수가 많다. EXP-001 run 1회의 실측 시간으로 다시 추정해야 한다(`unknown`).
- **사용자 학습 시간:** LDM 확인 질문 R1–R3과 DEMON band-pass가 미확인이다. 결정 대기가 일정 지연의 주 원인이 될 수 있다.
