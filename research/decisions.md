## D-2026-10-06-01: 생성기는 latent diffusion(LDM)을 먼저, latent flow matching(LFM)은 나중에

- 날짜: 2026-10-06
- 결정 내용: 생성 모델을 다룰 때 LDM을 먼저 구축하고, LFM은 같은 오토인코더와 조건에서 나중에 비교한다.
- 결정 배경: 사용자 선택. 외부 AI 답변(`research/hypotheses.md` H-LFM 절)도 "LDM을 강한 기준선으로 먼저"를 권했다.
- 고려한 대안: LFM 먼저(이전 PG-MCLDM 방식), 두 모델 동시 비교
- 근거:
  - 오디오 분야에서는 LDM 선례(AudioLDM 등)가 LFM보다 많다. 이 지식베이스에서는 원문을 확인하지 않았다.
  - 이전 실험에서 CFM과 diffusion의 차이는 신뢰구간 안이었다(PG-MCLDM E2 vs E6). 따라서 순서를 바꿔도 잃는 것은 적다.
- 현재 상태: 확정. 생성 트랙(후순위)과, 증강 트랙에서 생성 기반 증강을 시도할 때 적용한다.
- 주의 (이전 실험 교훈): DGM과 ot-cfm의 DDIM 약점은 설정(ε-예측, x̂₀ clamp ±6, ZTSNR 미적용) 때문이었다. LDM 설정은 v-예측과 적절한 noise schedule로 시작한다.
- 재검토 조건: 오토인코더 복원 상한(토널·DEMON 보존)이 통과하지 못하면 LDM과 LFM 모두 보류한다.

## D-2026-10-13-01: 특징 추출 논문 재현은 "원문 분할 → DEMONet 분할 → 선박 분할" 3단으로 성능 하락폭을 잰다

- 날짜: 2026-10-13
- 결정 내용 (사용자): LOFAR·DEMON 재현 모두 다음 순서로 진행한다.
  1. 원문이 무작위 분할을 쓰면 그 무작위 분할로 재현을 먼저 검증한다.
  2. DEMONet 분할 기준으로 평가한다.
  3. 선박 단위 분리로 평가한다.
  - 목적: 분할을 엄격하게 할수록 성능이 얼마나 떨어지는지(하락폭) 본다.
- "DEMONet Table 9, 10"의 해석 (Teacher 확인, `confirmed`):
  - DEMONet(arXiv 2411.02758)의 Table 9는 frame 길이 실험이다. 분할 표는 **Table 10(DeepShip)과 Table 11(ShipsEar)**이다.
  - DEMONet Table 10의 DeepShip test ID는 EXP-002-PC에서 쓴 Xu J. 2023 Table 9와 같다(cargo 26개, tug 18개 ID 일치 확인).
  - 사용자가 말한 "Table 9, 10"은 이 분할 표들을 가리킨다고 해석했다. 사용자 확인은 받지 않았다.
- 알려진 위험: DEMONet Table 10 분할은 test의 73.9%가 train과 같은 선박이다(OP10). 따라서 2단계는 "녹음 분리, 선박 누수 있음"이다.
- 적용:
  - LOFAR(Cho & Ha 2024): R1(이미지 무작위, 완료) → R2c(DEMONet 분할, 신규) → R2b(선박, 완료). R2a(녹음 단위 자체 분할)는 보조로 남긴다.
  - DEMON(Wang 2026): 원문은 분류도 데이터 분할도 하지 않는다(단일 신호 특징 추출, 합성 + 비공개 호수 데이터). 이 결정을 그대로 적용할 수 없다. 사용자 확인이 필요하다.
- DEMON 적용 (사용자 결정, 2026-10-13): 분할 사다리는 적용하지 않는다. 지금 계획(합성 신호 검증)을 유지하고, 분할 사다리는 LOFAR에만 적용한다.
- 상태: 확정

## D-2026-10-13-02: 조건부 LDM 생성을 물리 기반 증강의 한 방법으로 본다

- 날짜: 2026-10-13
- 결정 내용 (사용자): DEMON·LOFAR 특징을 조건으로 쓰는 조건부 LDM 생성을 1순위 목표(물리 기반 증강, D-2026-10-06-02)의 후보 방법 중 하나로 둔다.
  - 1순위 목표 자체는 바꾸지 않는다.
  - D-2026-10-06-02의 "생성은 후순위"는 "WAV 복원과 생성 품질 자체를 목표로 하는 연구는 후순위"로 좁혀 읽는다.
- 결정 배경:
  - 사용자는 latent DDPM에 DEMON·LOFAR(광대역·협대역) 특징을 반영하고 싶어 한다.
  - LOFAR·DEMON 재현의 목적은 이 특징 추출의 가능성을 보는 것이다.
  - 지도교수가 처음 준 방향이 생성 모델이다.
- 고려한 대안:
  - 생성을 1순위로 올린다. 이 경우 성공 지표(OP11)가 없다.
  - 생성을 계속 후순위로 둔다. 이 경우 사용자의 동기와 재현 실험의 목적과 맞지 않는다.
- 근거: 조건 c를 물리 손잡이(f_s, 하모닉, tonal 위치)로 조작하면 "새 선박 같은 변이"(H-AUG-2)를 만드는 수단이 된다. `inferred`이며 직접 근거는 없다.
- 이 결정에 따라붙는 조건:
  1. **평가는 증강 기준으로 한다.** 선박 분리 분할에서 UATR 성능이 판정 기준이다. 생성 품질 지표는 보조로 쓴다.
  2. **비교 대상이 필요하다.** 범용 증강(EXP-002)과 비생성 물리 증강(신호 수준 조작)을 함께 비교한다. 조건부 LDM이 더 비싼 만큼 더 나은지 보여야 한다.
  3. **진행 순서:** AE 복원 상한(tonal·DEMON 보존) → 무조건 LDM → 조건부 LDM(H-LDM-2) → 조건 조작 증강 → UATR 평가. 한 번에 하나만 바꾼다.
  4. **순환 논증 금지:** 조건으로 쓴 특징만으로 생성물을 평가하지 않는다.
- 현재 상태: 확정. 실행 계획은 아직 없다. 사용자가 LDM 원문을 공부하는 중이다.
- 재검토 조건:
  - AE 복원 상한이 tonal·DEMON 보존 기준을 통과하지 못하는 경우
  - 조건부 LDM 증강이 비생성 물리 증강보다 낫지 않은 경우
  - 지도교수의 방향 지시가 바뀌는 경우

- 근거: 판정 틀은 그대로 둔다. 선박 분리 UATR이 주 판정이다(D-2026-10-13-02 조건 1).

## D-2026-10-20-01: DEMON 평가기는 CPW 백색화(W)로 통일한다

- 날짜: 2026-10-20
- 결정 내용 (사용자): DEMON 평가기 e를 두 데이터셋 모두 W(band-pass 100–2000 Hz 안에서 CPW X/|X| → 포락선 → 최대 피크/배경 중앙값)로 통일한다.
  - DeepShip: W 사용 (G0 v2 AUC 0.762 [0.713, 0.809])
  - ShipsEar: W가 기준 미달(0.683)이므로 **DEMON 조건·평가를 보류**한다. tonal 중심으로 간다.
- 결정 배경: G0 v2(thesis 70de47d). 사전 규칙대로 하면 DeepShip은 W, ShipsEar는 V1(0.720, CI가 0.70 포함)을 쓰게 된다.
- 고려한 대안: A. 사전 규칙대로 데이터셋별 평가기를 쓴다.
- 근거:
  - V1은 표본에 따라 판정이 뒤집혔다(DeepShip 0.693 → 0.713).
  - ShipsEar 배경 소음 클래스 E에서 V1 AUC가 0.770으로 선박 클래스보다 높았다. W에서는 0.573이었다. V1이 진폭 변조가 아닌 구조에도 반응하는 것으로 보인다(`inferred`, 미확인).
  - CPW는 합성 신호에서 beating을 지웠고(신뢰비 14.7 → 1.39), 날개 변조는 남겼다(23.5 → 20.5). 근거 등급은 인접 분야 근거다(베어링 진단 CPW).
- **사후 결정 표시:** G0 v2 결과를 본 뒤 사전 규칙(데이터셋별 최고 AUC 채택)을 바꾼 결정이다. 논문에는 사전 규칙의 결과와 함께 이 변경과 이유를 쓴다.
- 하모닉 검출(H)은 실데이터에서 검출력이 없었다(실제 선박 클립의 90–97%가 component 0). 5 s 클립에서는 쓰지 않는다. 긴 구간(30 s 이상)은 시험하지 않았다.
- 현재 상태: 확정.
- 재검토 조건: 더 긴 클립을 쓰게 되는 경우, ShipsEar에서 W를 다시 시험할 근거가 생기는 경우.

## D-2026-10-21-01: E1-AE 대상 도메인은 MEL + STFT + CQT

- 날짜: 2026-10-21
- 결정 내용 (사용자): E1-rep 사전 규칙이 고른 MEL + STFT에 CQT를 더해 세 도메인에서 AE 보존 게이트를 본다.
- 결정 배경: E1-rep 판정(thesis 2699960). 점수 MEL 0 > STFT −0.51 > CQT −0.66. STFT와 CQT의 차이는 0.15 pp로 run 잡음(1.1 pp)보다 훨씬 작아 사실상 동률이다.
- 추가 기준(사전 규칙에 없던 것, 명시): **생성물의 물리 평가 가능성.** WAV 복원을 미루었으므로 생성물의 tonal은 특징 이미지에서 재야 한다. 256칸 선형 STFT는 칸당 31 Hz(50–400 Hz가 11칸)이고, MEL은 실제 해상도가 약 15.6 Hz다. CQT는 저주파일수록 세밀해 tonal을 이미지에서 평가할 수 있는 유일한 후보다(`inferred`).
- 고려한 대안: A. 규칙대로 MEL + STFT. C. 고해상도 STFT로 생성하고 MEL로 변환해 분류(설계 변경이 크다. E1-AE 뒤에 다시 검토한다).
- 사후 결정 표시: 규칙이 고른 2개는 유지하고 하나를 더하는 것이다. 판정을 뒤집지 않는다.
- 현재 상태: 확정.
- 재검토 조건: CQT AE가 게이트를 통과하지 못하는 경우, 생성 도메인 분리안(C)을 채택하는 경우.
