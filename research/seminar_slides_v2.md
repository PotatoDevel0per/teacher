### S5b. [신규] Ships-disjoint 5-fold를 어떻게 구성했나 [검증]
- 핵심 메시지: **선박 하나의 모든 녹음은 한 fold에만 들어간다. 모든 클립은 test에 정확히 한 번 나온다.**
- 구성 순서(흐름도):
  1. 그룹 정의
     - DeepShip: 선박명을 대문자로 바꾸고 공백을 정규화한다. 잘린 이름 "QUEEN OF"는 한 그룹으로 묶는다. 선박명을 확인할 수 없는 Tanker 10개 녹음(126 클립)은 제외한다.
     - ShipsEar: ship_id 단위. 배경(E)은 녹음 단위.
  2. fold 배정: 클래스별로 그룹을 5 fold에 나눈다. 클립 수가 fold마다 약 20%가 되게 하고, 무작위 재시작 탐욕 배정(2,000회, seed 0)을 쓴다. 모든 fold에 클래스마다 그룹이 1개 이상 들어간다.
  3. val 선택: fold k의 train 그룹에서 클래스별로 클립 약 15%가 되는 그룹을 고른다.
  4. 검증: 공유 그룹 0, 공유 녹음 0, 클립별 test 1회, 모든 fold의 test와 val에 전 클래스가 있다.

### S9a. [신규] broadband와 tonal을 어떻게 나눴나, 그리고 O_rp
- 핵심 메시지: **같은 클립의 진폭 스펙트럼을 '매끈한 모양(broadband)'과 '뾰족한 선(tonal)'으로 나누고, 위상을 섞어 시간 구조를 지웠다.**
- 계산 순서(5 s 클립 x, 16 kHz):
  1. X(f) = FFT(x). 주파수 간격 Δf = 0.2 Hz
  2. 평활 진폭: A_s(f) = sqrt( median_{20 Hz}(|X(f)|²) / ln 2 )
     - 20 Hz 폭(101 bin)의 median filter
     - ln 2 보정: |X|²의 median은 평균의 ln 2배라서 평균 수준으로 되돌린다.
  3. 입력 3종(모두 위상 무작위화 φ ~ U[0, 2π)):
     - **O_rp**: |X(f)|·e^{jφ} → 원래 진폭 스펙트럼 전체(tonal + broadband)
     - **B (broadband만)**: A_s(f)·e^{jφ}
     - **T (tonal만)**: (|X(f)| / A_s(f))·e^{jφ} → 평탄한 바닥 위의 선만 남음
  4. IFFT → 파형 → 기존과 같은 MEL 추출
- **O_rp는 원본과 무엇이 다른가:**
  - 진폭 스펙트럼(어떤 주파수에 얼마의 에너지가 있는가)은 원본과 똑같다.
  - 위상을 무작위로 바꿔서 **시간 구조가 사라진다.** 펄스, 진폭 변조(DEMON 성분), 시간에 따라 변하는 tonal이 5 s 전체에 고르게 퍼진다.
  - O_rp는 B·T와 공정하게 비교하기 위한 기준이다. 세 입력이 같은 위상을 받으므로 차이는 진폭 스펙트럼에서만 난다.
  - 원본 MEL과 O_rp의 차이가 곧 시간 구조의 기여다. Ships-disjoint DeepShip에서 +5.6 pp였다.
- 경계(노트): 폭이 약 10 Hz 이상인 넓은 협대역 성분은 B에 남고 T에서는 빠진다.
- 그림: `S09_e1src_spectra_O_B_T.png`(필수), `S09_e1src_mel_vs_cqt.png`

## 4부. 물리 평가기

### S10a. [신규] 평가 용어: AUC, PSD, CPW
3단 구성으로 만든다.

**AUC (Area Under the ROC Curve)**
- 정의: 무작위로 고른 실제 선박 클립의 점수가 무작위로 고른 대조군 클립의 점수보다 높을 확률이다.
- 식: AUC = P(s_real > s_control) + ½·P(s_real = s_control). Mann–Whitney U / (n_real · n_control)와 같다.
- 읽는 법: 0.5는 구별하지 못함, 1.0은 완벽하게 구별함. 이 연구의 사용 기준은 tonal ≥ 0.80, DEMON ≥ 0.70(구현 휴리스틱)이다.
- 이 연구에서 점수 s: tonal은 클립당 tonal line 수, DEMON은 신뢰비(최대 피크 ÷ 배경 중앙값)다. CI는 클립 bootstrap 2,000회로 구했다.

**PSD (Power Spectral Density, 전력 스펙트럼 밀도)**
- 정의: 신호의 전력이 주파수별로 어떻게 분포하는가.
- 식: P(f) ≈ |X(f)|² / (f_s · Σw²) (periodogram). Welch 방법은 짧은 구간의 periodogram을 평균한다.
- LTAS: 긴 시간에 걸쳐 평균한 PSD. 잡음 제거 전후 비교에 쓴다.
- 이 연구에서: tonal 대조군은 "PSD를 20 Hz median으로 평활한 잡음"이다. broadband 모양은 남고 tonal 선은 사라진다. FocuS-MN 재현에서는 원문 Fig. 9와 같은 PSD 비교에 썼다.

**CPW (Cepstrum Pre-Whitening, 켑스트럼 사전 백색화)**
- 정의: 스펙트럼의 진폭을 모두 1로 만들고 위상만 남겨, 강한 tonal이 포락선을 지배하지 못하게 한다.
- 식(band 100–2000 Hz):
  - y = BP(x), Y(f) = FFT(y)
  - Y_w(f) = Y(f) / (|Y(f)| + ε) (band 안), 0 (band 밖), ε = 10⁻¹²·max|Y|
  - y_w = IFFT(Y_w)
  - e(t) = |hilbert(y_w)|² − 평균 → 500 Hz로 다운샘플 → DEMON 스펙트럼 = |FFT(e·Hann)|, 0–100 Hz
  - 신뢰비 = (2–100 Hz 최대 피크) / (2–100 Hz 중앙값)
- 왜 필요한가: 가까운 두 tonal f₁, f₂는 포락선에 |f₁ − f₂| 주파수의 beating을 만들어 가짜 프로펠러 변조처럼 보인다. 진폭을 1로 만들면 tonal의 크기 이점이 사라져 beating이 약해진다. 반면 진짜 진폭 변조는 측파대 위상 관계에 남아 유지된다.
- 근거 등급: 베어링 진단의 포락선 분석에서 쓰는 방법이다(인접 분야). 수중 DEMON에 쓴 사례는 확인하지 못했다.

### S11. 물리 평가기 판별력 검증: tonal [검증]
- 핵심 메시지: **tonal 평가기는 실제 선박과 tonal을 지운 대조군을 거의 완벽하게 구별한다.**
- 평가기: 1 s window STFT(Δf = 1 Hz) → TPSW 배경 정규화 → 6 dB 이상 피크 → 5 s의 50% 이상 지속 → tonal line
- 대조군: 같은 클립의 PSD를 평활한 잡음(tonal만 지움)
- AUC: DeepShip 0.998, ShipsEar 0.937 → 사용
- 그림: `S11_g0_dist_deepship.png`, `S11_g0_unit_test.png`

### S12. 물리 평가기 판별력 검증: DEMON과 beating [검증]
- 핵심 메시지: **가까운 tonal 두 개의 beating을 프로펠러 변조로 착각한다. CPW가 이를 지운다.**
- 대조군: 위상 무작위화(진폭 변조만 지움)
- 실패 사례: 위상을 섞어도 41.4 Hz 피크가 남는다(`S12_demon_beating_failure.png`).

## 5부. 잡음 제거 앞단

### S13. 잡음 제거 논문 소개: FocuS-MN (Gu et al., JMSE 14:621, 2026)
- 동기: 배경 잡음(녹음 조건 단서)을 지우면 Ships-disjoint 인식이 좋아질까?
- 데이터: ShipsEar 선박 녹음 + 배경 녹음(E)을 −5 dB로 섞음. test는 처음 보는 선종 4개(준설선, 예인선, 트롤선, 파일럿선)
- 원문 결과: SDR 3.77 / SDRi 8.61 / SSNR 3.83 dB

### S13a. [신규] FocuS-MN의 잡음 제거 방식
- 핵심 메시지: **STFT 크기에 곱할 마스크(0–2)를 예측한다. 위상은 입력 그대로 쓴다.**
- 블록도(왼쪽 → 오른쪽):
  1. 입력: 3 s, 16 kHz 파형 → STFT(창 400, hop 100, Hann) → 압축 크기 |X|^0.3과 위상 ∠X를 2채널로 쌓는다.
  2. 인코더: Conv2D(2 → 32ch) + InstanceNorm + PReLU → Dilated DenseNet(팽창 1, 2, 4, 8) → Conv2D
  3. 중간부: [학습형 다운샘플(시간·주파수 1/2) → FSMN 블록 → 학습형 업샘플] × M = 6단계, 가운데에 latent FSMN N = 6개
     - 학습형 리샘플링: 채널마다 학습한 가중치로 인접 2칸을 가중 평균해 1/2로 줄이고, 업샘플은 각 칸을 2번 반복한다.
     - FSMN: 선형층 + 과거·미래 방향 depthwise 1D conv "메모리"(출력 = X + H_left + H_right). RNN 없이 긴 시간 문맥을 본다.
  4. 디코더: Dense block → sub-pixel ConvTranspose → 학습형 sigmoid 마스크 M = β·σ(S ⊙ Z), β = 2
  5. 출력: (M · |X|^0.3)^(1/0.3) · e^{j∠X} → iSTFT
- 파라미터 0.34 M
- 학습(2단계):
  - 1단계: 압축 크기 MSE
  - 2단계: 파형 SI-SNR 손실. 우리 재현에서는 압축 크기 MSE(가중 140)를 더했다.
  - optimizer: Adam, lr 5e-5, cosine, batch 16
- 5 s 이상 입력: 3 s 창을 50% 겹쳐 처리하고 Hann 가중 overlap-add로 잇는다.
- 지표(노트): SDR = 10 log₁₀(‖s‖² / ‖s − ŝ‖²), SDRi = SDR(출력) − SDR(입력 혼합), SSNR = 20 ms 프레임별 SNR의 평균

### S15. [수정] ShipsEar로 학습한 잡음 제거기를 DeepShip 분류 앞단에 [검증]
- 핵심 메시지: **고주파(2–8 kHz)를 크게 지우는 잡음 제거는 DeepShip 분류에 해롭다. DC를 빼도 마찬가지였다.**
- 배경: 이 잡음 제거기는 ShipsEar만 학습했으므로 DeepShip에 써도 누출이 없다.
- 발견: DeepShip 클립 에너지의 98%가 DC였다. 첫 실험에서는 DC를 빼지 않고 잡음 제거기에 넣었다.
  - DC가 큰 입력에서 잡음 제거기가 저주파 인공물을 만들었다(`S15b_dc_vs_nodc.png`).
  - DC를 빼고 혼합 성능을 재면 SDRi 7.07 dB다(기준 6.9 통과).
- 분류 결과(macro-F1, 원본 대비 Δ, seed 3 평균) [검증]:

| fold | 원본 | DC 미제거 입력 | DC 제거 입력 |
|---|---|---|---|
| 1 | 48.74 | +7.24 | −2.19 |
| 2 | 64.65 | −7.63 | −2.02 |
| 3 | 55.97 | −5.25 | −3.80 |
| 4 | 61.06 | −6.99 | −3.10 |
| 5 | 60.47 | −11.50 | −10.61 |
| 5 fold 평균 | 58.18 | −4.83 (해로움, 4/5) | **−4.34 (해로움, 5/5)** |

- 읽는 법:
  - DC를 빼자 fold1–4의 진폭(+7 ~ −8)이 −2 ~ −4로 줄었지만 5 fold 모두 해롭다. 클래스별로는 Passenger −8.8이 가장 크다.
  - DC 미제거 fold1의 +7.24는 큰 선박 두 척이 만든 예외였다.
- 그림: `S15b_dc_vs_nodc.png`(같은 클립: 원본 / DC 미제거 입력 출력 / DC 제거 입력 출력 / LTAS)

### S16. [수정] UniqueShip 실제 배경으로 학습한 잡음 제거기 [검증, 배지: "UniqueShip fold1 안에서 누출 없음"]

### S17b. [신규] DeepShip용: DeepShip 기간·선박을 완전히 제외한 UniqueShip 잡음 제거기 [설계 완료, 학습 대기]
- 왜 필요한가: UniqueShip과 DeepShip은 같은 해역·기간이다. 선박 140척이 겹치고(DeepShip 클립 71%), 같은 날 같은 MMSI 녹음이 180개 있으며, 배경 날짜도 155일 겹친다.
- 설계:
  - DeepShip 기간(2016-05 ~ 2018-10) 이후의 UniqueShip 데이터만 쓴다(2018-11 ~ 2023-12).
  - DeepShip과 겹치는 MMSI와 선박명은 뺀다.
  - 학습 풀: 선박 클립 24,835(884척), 배경 11,446(299일)
  - 누출 점검: 날짜와 선박명 겹침 0
- 판정(학습 전 등록):
  - DeepShip 혼합 SDRi ≥ 6.9 dB
  - ShipsEar 학습 모델(7.07) 대비 클립별 짝 비교로 평균 +0.5 dB 이상이고 CI가 0을 넘으면 "낫다"
- 상태: 학습 대기. 위의 DC 제거 입력 분류 결과를 보고 학습 여부를 정한다. **결과 숫자 없음.**
