## 3. 작업 1: 평가기 e 구현 (`core/evaluate/`)

입력은 16 kHz 파형 5 s 클립이다. 특징 캐시가 아니라 파형에서 계산한다. 그래야 도메인과 무관하다.

- tonal 평가기
  - 긴 창 STFT(창 1 s, Δf ≈ 1 Hz, hop 0.25 s) → 10–1000 Hz → 배경 정규화(TPSW) → 피크 검출 → 시간 지속(프레임의 50% 이상에서 같은 bin ±1) = tonal line.
  - 출력: line 목록(주파수), 클립당 line 수, line별 SNR(dB).
  - 두 클립 비교(원본 vs 복원·생성): 원본 line을 정답으로 P/R/F1(±1 bin).
  - TPSW 구현은 EXP-LOFAR-001(`/jhlee/UWShipNoise/recognition/LOFAR/exp_lofar_001/code/make_lofar.py`)을 참고한다. 이 실험은 confirmed 등급이다. 세부 파라미터는 GEN이 정하고 REPORT에 적는다.
- DEMON 평가기
  - 고정 band-pass 100–2000 Hz(EXP-DEMON-001의 BP-MID: 합성 신호 −15 dB에서 EEMD보다 +35 pp) → 포락선(Hilbert 크기 제곱) → 저역 통과 → 다운샘플 → 스펙트럼 0–100 Hz.
  - 출력: 최대 피크 주파수 f_pk, 신뢰비 = 피크 / 배경 중앙값.
  - 두 클립 비교: f_pk 일치(±1 bin), 신뢰비 비율.
  - EXP-DEMON-001(`/jhlee/UWShipNoise/features/DEMON/run_stage2b1_bpmid.py`)을 참고한다.
- 단위 테스트: 합성 신호로 검증한다. 예: 알려진 주파수의 tonal 3개 + 광대역 잡음, f_s 8 Hz 진폭 변조. 정답을 회수하는지 `exp/E0_g0/`에 기록한다.

## 4. 작업 2: G0 실데이터 판별력 (`exp/E0_g0/`)

- 표본: 데이터셋마다 클래스별 50 클립. **fold1 test 선박은 제외**하고 고른다(평가기 조정에 test 선박을 쓰지 않으려는 것). seed 0. 같은 녹음에서 최대 3 클립.
- 대조군(같은 클립에서 만든다):
  - tonal 대조군: 클립의 PSD를 주파수 방향으로 매끄럽게 만든 뒤(median filter 약 20 Hz) 그 PSD를 가진 잡음. 광대역 모양은 남고 협대역 선은 사라진다.
  - DEMON 대조군: 위상 무작위화 surrogate. PSD는 같고 진폭 변조는 사라진다.
  - 주의: 위상 무작위화는 PSD를 보존하므로 tonal 대조군으로 쓰면 안 된다.
- 지표: tonal = 클립당 line 수(또는 line SNR 합), DEMON = 신뢰비. 실제 vs 대조군의 AUC(ROC).
- **판정(사전 등록, 구현 휴리스틱):**
  - tonal: 데이터셋별 AUC ≥ 0.80이면 tonal 평가기를 사용한다.
  - DEMON: 데이터셋별 AUC ≥ 0.70이면 사용한다. 0.70 미만이면 그 데이터셋에서 DEMON 조건·평가를 보류한다(DeepShip은 변조가 약하다는 보고가 있다, DEMONet 노트).
  - 결과를 본 뒤 임계값이나 파라미터를 바꾸지 않는다. 바꿔야 하면 Teacher에게 먼저 묻는다.
- 보고: 클래스별 분포 그림, AUC, 실패 사례 5개, 파라미터 표, 클립 하나당 계산 시간.

## 5. 작업 3: AE 코드 기반 (`core/ae/`, 학습 없음) — **보류 (2026-10-19 사용자 결정: E1-rep 종료 후 별도 지시)**

- 도메인과 무관한 2D AE(입력 1 × 256 × 256): encoder·decoder, KL 정규화 옵션(가중치 기본 1e-6, LDM 원문 부록 G), latent 재스케일(z/σ̂, 첫 배치에서 추정), 다운샘플을 축별로 설정(주파수 f_F, 시간 f_T).
- 손실: 복원 L1 + 선택적 patch adversarial. LPIPS는 쓰지 않는다(ImageNet VGG, 스펙트로그램 근거 없음). 물리 손실은 넣지 않는다.
- 평가 hook:
  - (a) 클래스 보존: CLS가 만든 E1-rep의 `best.pt`(실데이터 분류기)를 복원본에 적용하는 함수
  - (b) tonal 보존: 해당 도메인 해상도로 원본 대비 F1을 내는 함수
- CPU 단위 테스트만 한다(작은 입력으로 forward/backward, shape 확인). 학습 설정과 게이트 임계값은 E1-rep 결과 뒤에 Teacher가 지시서로 정한다.
