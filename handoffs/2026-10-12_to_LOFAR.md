# Handoff → LOFAR 세션: LOFAR 특징 추출 논문 1편 선정·검증·최소 재현

- 작성: 2026-10-12 (teacher 세션, `/jhlee/teacher`)
- 받는 곳: `LOFAR` 세션
- 사용자 요청: "'LOFAR' 세션에는 마찬가지로 LOFAR 도메인에서 특징 추출하는 SCI급 논문 하나 선정해서 재현해 보라고 하자."
- 같은 구조로 진행 중인 작업: `DEMON` 세션(`handoffs/2026-10-12_to_DEMON.md`, Wang 2026 JMSE)

## 1. 연구 목표 (맥락)

- 사용자는 석사과정이고, 수중 선박 소음 인식(UATR)을 연구한다.
- 1순위: **물리 기반 증강**으로 선박(MMSI) 단위 분리 조건에서 일반화를 개선한다. 주 데이터는 UniqueShip이다.
- LOFAR는 tonal(저주파 narrow 선)의 주파수, 하모닉 계열, 시간 변화를 추출하는 수단으로 검토한다.
  - 증강 설계에 쓸 수 있다. 예: tonal을 보존하는지, tonal을 이동하는 증강.
  - 생성 오디오의 tonal 보존 평가(OP6)에도 쓸 수 있다.
- 범위: 공개 데이터셋에 대한 합법적·방어적·학술적 신호 분석만 한다. 군사적 교란·기만·공격 응용은 다루지 않는다.

## 2. 확정된 사실

- LOFAR의 기본 절차: 긴 window로 STFT → 저역 선택 → 배경 정규화(TPSW 등) → 시간 축 waterfall
  - 주파수 분해능은 Δf = fs/N이다. 5 s 클립이면 Δf는 0.2 Hz보다 작아질 수 없다.
  - 개념 노트: `/jhlee/teacher/research/concepts/stft_lofar_demon.md`
- 이전 실험(미검증, 근거로 쓰지 않는다)에서 관찰한 것
  - Mel+HiFi-GAN에서 tonal 피크 일치율이 22.6%로 우연 수준이었다.
  - 3 dB 임계에서 오경보가 프레임당 779개였다.
  - → tonal 검출 임계와 평가 지표 설계가 핵심 난점이다.
- 데이터셋에는 tonal 주파수 정답이 없다. 정량 평가는 합성 신호로 해야 한다.

## 3. 선정 논문 (잠정)

**Han, Li, Liu, Ma 2020, "DeepLofargram: A deep learning based fluctuating dim frequency line detection and recovery", *J. Acoust. Soc. Am.* 148(4):2182–2194, DOI 10.1121/10.0002172**
- 프리프린트: arXiv 1912.00605 (https://arxiv.org/abs/1912.00605)
- 확인 범위: 서지(Crossref)와 검색 요약뿐이다. **원문은 아직 확인하지 않았다.**
- 검색 요약에 따른 내용: LOFARgram에서 약하고 흔들리는(fluctuating, dim) 주파수 선을 딥러닝으로 검출하고 복원한다.

선정 이유 (teacher 판단, `inferred`)
- LOFAR에서 얻을 핵심 물리 특징인 **tonal 주파수 궤적**을 직접 출력한다.
- 단일 채널 LOFARgram을 입력으로 쓴다. 배열이 필요 없어서 DeepShip과 UniqueShip에 적용할 수 있다.
- SCI(JASA)이고 arXiv 원문이 있어 접근성이 좋다. 후속 연구(Multiple DeepLofargram, JASA 2026)가 있어 계보도 이어진다.

**예비 후보** (원문 확인에서 탈락할 때만, 이 순서로)
1. Xiao, Liu, Sun, Han 2026, "Multiple DeepLofargram: Weakly supervised detection and recovery of multiple dim frequency lines for underwater acoustic targets", *JASA* 160(3):2608–2626, DOI 10.1121/10.0046669
   - 여러 선을 동시에 다루고, 약지도 학습이다.
2. 고전 비학습 방법: HMM 기반 주파수 선 추적 계열(예: Streit & Barrett, IEEE TASSP 1990). **서지는 이 세션이 확인하지 않았다.** 이 계열로 가게 되면 원 서지부터 확인한다.

제외한 후보
- Shi, Piao, Guo 2024 JASA 156(5):3320 (10.1121/10.0034356): 주파수-방위-시간 공간을 쓰므로 배열이 전제된다.
- Appl. Sci. 2025 (10.3390/app15136952): 비공개 해군 데이터로 한 분류 연구다.

## 4. 요청 작업 (단계마다 끝에 teacher에 보고)

### 단계 1. 원문 확보와 확정 판정
- arXiv 판을 받아 `/jhlee/teacher/papers/pdf/2020_han_deeplofargram.pdf`에 저장한다.
  - arXiv 판과 JASA 게재판이 다를 수 있다. 버전을 기록한다.
  - 게재판이 필요하면 사용자에게 요청한다.
- 원문 전체를 읽고 다음을 확인한다. 초록만 보고 단정하지 않는다.
  1. 입력: LOFARgram 생성 파라미터(window, Δf, 정규화, 주파수 범위)
  2. 출력: 선의 존재 여부, 픽셀 마스크, 주파수 궤적 중 무엇인가
  3. 학습 데이터: 합성 선 모델(SNR, 요동 모델, 선 폭), 실데이터 사용 여부, 라벨을 만든 방법
  4. 네트워크 구조와 학습 설정, 필요한 계산량
  5. 평가 지표와 비교 대상(TPSW + 임계, HMM 추적 등), 반복 실행 여부
  6. 코드나 데이터 공개 여부
  7. 저자가 밝힌 한계
- **확정 기준**: 아래 둘을 모두 만족해야 한다. 만족하지 않으면 예비 후보 1로 같은 절차를 밟는다.
  - (a) 합성 데이터 생성과 학습에 필요한 파라미터가 대부분 원문에 있다. 빠진 것은 목록으로 만든다.
  - (b) 정답 기반 정량 평가가 최소 1개 있다. 예: 검출률, 오경보율, 주파수 오차.
- 산출물
  - 논문 노트: `/jhlee/teacher/papers/notes/2020_han_deeplofargram.md`. 같은 폴더의 다른 노트 형식을 따르고, `confirmed`와 `inferred`를 구분한다.
  - metadata yml의 status와 pdf_path를 갱신한다.

### 단계 2. 최소 재현 (합성 신호만)
- **2a 원문 조건 재현**
  - 원문의 합성 선 모델과 평가 조건을 그대로 쓴다.
  - 원문 표나 그림의 방법 간 순위와 경향이 맞는지 본다.
  - 기준 방법으로 **TPSW + 임계 검출**(비학습)을 반드시 함께 낸다.
- **2b 확장**(2a에서 경향이 맞은 뒤에만, 한 번에 한 축씩)
  - SNR
  - 선 요동 정도
  - **UniqueShip 조건(5 s 클립, Δf ≥ 0.2 Hz)**: 짧은 관측에서 성능이 얼마나 떨어지는지 본다.
- 판정 기준은 **실행 전에** 노트에 사전 등록한다.
  - 정답 기반 지표로 판정한다: 검출률, 오경보율, 주파수 RMSE.
  - 정답률의 허용 오차(예: 1 bin)도 미리 정한다.
- seed를 여러 개 쓰고 평균 ± sd를 보고한다.
- 원문을 변형하면 "논문 방법을 그대로 재현했다"고 쓰지 않는다.
  - 대신 "논문 방법을 재현함 / 일부 모듈을 재현함 / 아이디어 기반 변형" 중 정확한 표현을 쓴다.

  - 원문: `/jhlee/teacher/papers/pdf/2024_cho_lofar_hough_cnn.pdf`
  - 노트: `/jhlee/teacher/papers/notes/2024_cho_lofar_hough_cnn.md`

### R1. 논문 재현 (원문 분할 그대로)
- **데이터**
  - DeepShip `/jhlee/UWShipNoise/data/deepship`의 4클래스 일부 + ShipsEar Passenger ship
  - Table 1의 파일 수와 길이(Cargo 59 / Tanker 64 / Passenger 70 / Tug 32 파일)에 최대한 맞춘다.
  - 원문은 어떤 파일을 골랐는지 적지 않았다. 선택 규칙을 정해 기록한다.
  - ShipsEar 로컬 사본은 원본이 아니다(16 kHz, 무음 제거, 5 s 조각, `/jhlee/UWShipNoise/data/shipsear/DATASET_INFO.md`).
    - 먼저 원본(52,734 Hz)이 있는지 찾는다.
    - 없으면 같은 녹음의 연속 조각을 이어 1분을 만들고 편차로 기록한다.
- **LOFARgram**
  - 1분 비중첩 segment, fs 32 kHz, overlap 50%, 2–400 Hz, 256×256 → 928장 근처가 나와야 한다.
  - "윈도우 크기 100"은 단위가 모순된다. Fig. 7·8에서 15.2 Hz 하모닉이 분리되어 보이는 것과 256 프레임/1분을 근거로 window를 정하고, 근거를 기록한다.
  - 정규화는 원문에 없다. TPSW로 채우고 파라미터를 기록한다.
- **Hough**
  - 외곽선 추출(Canny 등, 원문 미기재) → 직선 Hough, 누적 임계 **130** → 기울기 0인 직선만 남겨 빨간 선으로 덧그린다.
- **분류기**
  - 3-layer CNN(Table 3), ResNet18, DenseNet121(Torchvision ImageNet 사전학습)
  - Adam, lr 1e-4, batch 16, 50 epoch, CE
- **분할과 평가**
  - 이미지 단위 7:3 무작위 분할(원문 그대로). 클래스 층화를 하고, seed마다 분할을 새로 뽑는다.
  - val이 없으므로 **50 epoch 마지막 모델**로 test를 평가한다.
- **arm**: 입력 2종(원본 / +HT) × 모델 3종 × seed 3개 = 18 run
- **재현 판정 (사전 등록)**
  - (i) ResNet18 원본 입력의 정확도 평균이 81.85 ± 5 pp 안
  - (ii) 모델마다 HT 이득(+HT − 원본, 같은 seed·분할에서 짝지어 비교)이 seed 3개 중 2개 이상에서 양수이고, 평균 ≥ +2 pp(원문 +3.56–5.70)
  - (i)과 (ii)를 모두 만족하면 "재현됨", 하나만 만족하면 "부분 재현"으로 판정한다.

### R2. 누수 없는 분할 (R1에서 분할만 바꾼다)
- R2a **녹음 단위 분할**: 같은 녹음의 segment는 train과 test 중 한쪽에만 들어간다. 7:3은 녹음 수 기준이고 클래스 층화를 한다.
- R2b **선박 단위 분할**
  - DeepShip: `ship_id.csv`의 선명으로 묶는다. UNMATCHED 10개는 녹음 단위로 처리한다.
  - ShipsEar: 선박 그룹 `/jhlee/UWShipNoise/recognition/UATR_SLM/UATR_SLM_split_study/04_splits/shipsear_inventory.csv`를 쓴다(미검증 세션 산출물이므로 확인 후 사용).
- 나머지 설정은 R1과 같다. 모델 3종 × 입력 2종 × seed 3개.
- 보고할 것
