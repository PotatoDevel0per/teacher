# Handoff → DEN: R-US — UniqueShip 5C-Bal로 잡음 제거기 학습과 성능 측정

- 작성: 2026-10-23 (Teacher). 받는 곳: `DEN`
- 사용자 결정(2026-10-23): DeepShip은 배경 녹음이 없으므로 제쳐 두고, **UniqueShip 5C-Bal만으로** 잡음 제거기를 학습하고 성능을 잰다.
- 근거: UniqueShip에는 같은 해역(ONC Strait of Georgia) 실제 배경 녹음이 42.7 h 있다(`/jhlee/teacher/research/datasets/uniqueship.md`). R2c 진단에서 결합형 L2가 약 7k step 뒤 학습을 망가뜨린다는 것을 확인했다(`exp/r2c_diag_verdict.json`).

## 1. 데이터 (모두 공식 fold1 분할을 따른다, 누출 없음)

- 원본: `/jhlee/UWShipNoise/data/uniqueship/5class_balanced/stage/main5_balanced/audio/<class>/*.wav` (32 kHz, 5 s). 목록·분할: `/jhlee/UWShipNoise/recognition/UATR_SLM/uniqueship_ds/{inventory.csv, splits/uniqueship_official_fold1.json, clip_mmsi.json}`
- 리샘플: soxr VHQ 16 kHz (thesis와 같다)
- 깨끗한 정답: 선박 4클래스(cargo, passengership, tanker, tug) 클립
- 잡음: background 클립
- **공식 fold1의 train / val / test를 선박·배경 모두 그대로 쓴다.** 공식 분할은 선박을 MMSI 단위로, 배경을 날짜 단위로 나눈다. 그래서 test 선박과 test 배경 날짜는 학습에 들어가지 않는다. 학습 전에 MMSI 겹침 0, 배경 날짜 겹침 0을 다시 확인한다.
- 혼합: 원문과 같이 **−5 dB SNR**(3 s 구간 에너지 기준), 3 s 구간.
  - 학습: 선박 클립 하나, 배경 클립 하나를 무작위로 짝짓고 각 5 s 안에서 3 s를 무작위로 자른다(on-the-fly, seed 고정).
  - val·test: 짝과 자르는 위치를 미리 고정한 혼합 집합을 만든다(seed 0). val은 클래스 균형으로 4,000개, test는 fold1 test 선박 클립 전체(약 11,177개)에 test 배경을 짝짓는다.
  - 비교용: UniqueShip 혼합에서 스펙트럼 차감 기준선도 잰다.

## 2. 모델과 학습 (R2 통과 구조 + R2c 진단 반영)

- 구조·손실: **시도 2b와 같다**(단계 잔차 on, 1단계 압축 크기 MSE, 2단계 140·압축 크기 MSE + SI-SNR, 파라미터 0.341 M).
- **optimizer: AdamW(decoupled), wd 0.01, lr 5e-5.** R2c 진단 결과에 따라 결합형 L2에서 바꾼다. 시도 2b와의 차이이므로 편차로 기록한다.
- 데이터가 크므로(train 선박 클립 약 10만 개) epoch 대신 **step으로** 운용한다. 초안(실행 전에 고정해서 등록):
  - batch 16, 1단계 최대 30k step, 2단계 최대 30k step
  - 2k step마다 고정 val 혼합으로 평가하고, 단계마다 patience 5회 평가(= 10k step)
  - cosine은 단계마다 남은 step 기준
  - 다른 값을 쓰려면 근거와 함께 등록한다.
- 가중치 norm, 기울기 norm, probe train 손실을 R2c 진단과 같은 방식으로 기록한다(퇴화 감시).
- GPU: **GPU 1 한 장**(GPU 0은 GEN의 E1-AE가 쓴다). 예상 시간을 먼저 보고한다.

## 3. 성능 측정 (사전 등록, `exp/rus_verdict.py`를 먼저 커밋)

- 주 지표: fold1 test 혼합의 SDR, SDRi, SSNR(R2와 같은 정의). 클래스별로도 낸다.
- 판정:
  - **"쓸 만함": SDRi ≥ 6.9 dB**(R2b·R2c와 같은 기준)
  - 참고: ShipsEar 재현 SDRi 8.68 dB, ShipsEar 모델을 DeepShip 혼합에 쓴 R2b는 5.86 dB
- 스케일 진단: 출력/정답 에너지 비, 최적 스케일 SDR
- **실녹음 진단(정답 없음):** 섞지 않은 fold1 test 선박 클립(5 s)과 test 배경 클립에 `denoise()`를 적용한다. 다음을 클래스별로 낸다.
  - 지운 에너지 비율
  - tonal 수 변화(thesis `core/evaluate/tonal.py` import)
  - LTAS 대역별 변화
  - 비교: ShipsEar 모델은 DeepShip 실녹음에서 87%, ShipsEar 실녹음에서 61%를 지웠다. 선박 클립은 덜 지우고 배경은 많이 지우는 것이 바람직하다.
